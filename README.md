# AI Marks Predictor

This is a Machine Learning web app built python and Streamlit.
## Features
- Predict student marks based on study hours and sleep hours
- Simple and intractive UI

## Tech Stack
- Python
- pandas
- Scikit-learn
- Streamlit 

## How to Run 
streamlit run app.py
